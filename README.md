# 阶梯轴自动上料与检测设备

本目录为按简历项目重新建立的可编辑机械设计包。关键自制件采用 SolidWorks 原生草图、拉伸、凸台等特征建模；外购电机、减速机、气缸和振动盘为接口级简化件，并在 BOM 中单独标明。

## 简历基线

- 阶梯轴长度 60 mm、最大直径 20 mm
- 振动盘加直线轨道
- V 形块定位
- 气源压力 0.5 MPa

## 工程补全说明

- 阶梯轴按总长 60 mm、最大直径 20 mm 建模；其余台阶尺寸为工艺布置用设计值。
- 气缸按 0.5 MPa 气源选型核算，安装孔和行程为本次设计值。
- 振动盘只保留安装、料斗和出料接口，不宣称具备真实振动整列性能。

## 目录

- `SolidWorks/parts`：原生零件源文件，保留特征树。
- `SolidWorks/assemblies`：功能子装配与总装源文件。
- `STEP`：零件、子装配和总装交换格式。
- `Drawings`：关键零件与总装的 SolidWorks 工程图、PDF、DXF。
- `Screenshots`：零件、子装配和总装等轴测截图。
- `Documents`：参数、BOM、计算说明和制造说明。
- `Validation`：生成记录与打开验证记录。

## 装配状态

- 功能子装配内的零件按已复核设计姿态固定，避免再次拖动造成关节错位。
- 总装以基座/机架模块为固定基准，其余模块通过前视、上视、右视三组基准面配合定位。
- `Validation/assembly_correctness_report.json` 记录零件变换、模块配合和关节/支撑链闭合检查。
- `Validation/assembly_views` 提供正视、右视和等轴测复核图。

## 证据边界

这是数字化结构设计和可打开性验证，不等同于实机制造、装配、节拍、精度或负载试验。文件中不会把外购简化件、估算计算或软件打开检查写成实机结果。
