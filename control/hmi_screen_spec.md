# HMI画面设计

## 1. 总览

- 自动/手动/维护模式、当前状态、循环步骤、节拍、总数、OK数、NG数和良率。
- 安全回路、气压、相机、激光测微仪、PLC通讯和料箱状态。
- 启动、受控停止、复位按钮；安全功能不依赖普通HMI按钮。

## 2. 手动画面

- 每个气缸独立伸出/缩回，按住执行，动作前检查安全、气压和互锁。
- 振动盘启停及频率设定；相机和激光单次触发。
- 同一机构相反方向命令互斥，未在维护模式时禁止输出。

## 3. 参数与配方

- 产品编号、直径上下限、视觉配方、曝光、检测超时、气缸超时、振动盘频率和重试次数。
- 参数修改需要工程权限，记录旧值、新值、用户和时间。

## 4. 报警

- 当前报警、历史报警、首次发生时间、恢复时间和处理提示。
- 严重报警必须在现场原因消除后复位；不能用HMI屏蔽安全输入。

## 5. 统计与维护

- 循环时间趋势、OK/NG分布、连续NG、设备运行小时和气缸动作次数。
- 维护阈值：导轨润滑、过滤器排水、振动盘清洁、相机标定和测量基准件复核。
